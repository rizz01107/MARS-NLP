# Data

Nothing in `data/raw/uci`, `data/raw/zenodo` or `data/processed` is committed (see `.gitignore`): the Zenodo license is
unverified and third-party corpora should be obtained from their original sources.

| Roman Urdu Phishing SMS Dataset for Smishing Detection Research (G. Siddiq) | https://zenodo.org/records/21810885 (DOI 10.5281/zenodo.21810885) | **unverified** - check the Zenodo record | Roman Urdu / English originals |

## Reproduce
1. Download the UCI zip, extract `SMSSpamCollection` to `data/raw/uci/SMSSpamCollection`.
2. Download `phishing_dataset_1000.xlsx` from the Zenodo record to `data/raw/zenodo/phishing_dataset_1000.xlsx`.
3. `python -m src.build_dataset` -> `data/processed/mars_nlp_processed.csv` (+ `.xlsx`).
4. `python -m src.validate_data` (must report 0 critical failures).

`data/raw/scaffold/` holds the three originally supplied (empty) files, kept unchanged for the audit trail.

## Processed schema
README columns: `message_id, message, language, label, source_dataset, source_url, source_license, source_type, message_type,
is_code_switched, is_perturbed, perturbation_type, original_message_id, split` plus `cleaned_message`, `group_id`
(near-duplicate group used for splitting) and `language_confidence`. `message` is always the raw text.
`label` in {Legitimate, Scam}; `source_type` in {real_public_dataset, augmented_from_real}.

## Provenance, access and restrictions
* **SMS Spam Collection (UCI)** - Almeida, Gomez Hidalgo & Yamakami (2011). Public; stated as CC BY 4.0 on the UCI page (the bundled readme grants free use with a copyright and citation request). Download it yourself from the UCI link above.
* **Roman Urdu Phishing SMS Dataset (Zenodo, DOI 10.5281/zenodo.21810885)** - public record, but **no license was found in the supplied files**. Treat redistribution as not permitted until you have confirmed the license on the Zenodo record. For this reason no dataset rows (raw or processed) are committed to this repository, and files that contain message text (`experiments/results/error_analysis.csv`, `reports/tables/explain_examples.csv`) are git-ignored; they are regenerated by the pipeline.
* **Not committed:** `data/raw/uci/`, `data/raw/zenodo/`, `data/processed/mars_nlp_processed.{csv,xlsx}`, model checkpoints. **Committed:** the SHA-256 checksum (`data/processed/mars_nlp_processed.sha256`) and split fingerprints (`split_fingerprint.json`), which let you verify that your rebuilt corpus is identical to the audited one.
* The three files in `data/raw/scaffold/` are the originally supplied, empty scaffold (0 rows) kept for the audit trail.
